# Lakshit Verma — Creative Studio Portfolio

Static Netlify-ready portfolio (no npm/build step).

## Deploy on the SAME Netlify URL
1. Extract this ZIP.
2. Open the existing site in Netlify → Deploys.
3. Drag this extracted folder (containing index.html) to the manual deploy area.
4. Wait for published deploy; hard-refresh the original URL.

## Included
- index.html — portfolio content, SEO and accessible semantic markup
- style.css — editorial design, warm ivory, ink navy, cobalt and coral palette
- script.js — mobile navigation, scroll reveals and certificate lightbox
- assets/lakshit-profile.jpg — original profile photo, object-fit contain (uncropped)
- assets/apex-internship-certificate.png — original internship certificate
